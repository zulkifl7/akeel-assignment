# Student Marks Management System (Tkinter GUI)

## 📌 Objective

This project implements a **Student Marks Management System** using **Python Tkinter**.
It is an extension of the text-based version practiced in class, now built with an interactive **Graphical User Interface (GUI)**.

⚠️ **Note**:
Follow **only the given instructions** and build strictly within this scope.
Do **not** add extra features or functionality beyond what is described below.

The system is divided into **three programs**:

1. **Data Entry GUI** – Enter subjects, students, and marks; save data to a text file.
2. **File Reader GUI** – Load and display saved data in a formatted table.
3. **Report Generator GUI** – Generate reports with totals, averages, rankings, subject analysis.

## 🚀 Usage Instructions

### 1. **Data Entry GUI (`data_entry_gui.py`)**

* Run the program:

  ```bash
  python data_entry_gui.py
  ```
* Features:

  * Enter **number of subjects** → dynamically generate subject name fields.
  * Enter **number of students** → dynamically generate student name + marks entry fields.
  * Click **Save Data** → data is written to `student_data.txt` in aligned columns.

**Example saved file (`student_data.txt`):**

```
Name     English  Maths  Science
John     25       80     70
Albert   50       90     85
```

---

### 2. **File Reader GUI (`file_reader_gui.py`)**

* Run the program:

  ```bash
  python file_reader_gui.py
  ```
* Features:

  * Click **Load Data** → reads `student_data.txt` and displays contents in a Tkinter **Text widget / LabelFrame**.
  * Alignment is preserved exactly as in the file.

---

### 3. **Report Generator GUI (`report_generator_gui.py`)**

* Run the program:

  ```bash
  python report_generator_gui.py
  ```
* Features:

  * Reads `student_data.txt`.
  * Calculates and displays in tabular format:

    * **Total & average marks per student**
    * **Ranking (place) based on total marks**
    * **Maximum marks per subject**
    * **Average marks per subject**
    * **Best performer in each subject**

**Example Output Table:**

```
---------------------------------------------------
Name              English     Maths     Science  Total  Avg   Place
John              25          80        70       175    58.3  2
Albert            50          90        85       225    75    1

Subject  Max      50          90        85
Subject  Avg      37.5        85        77.5
Best     Person   Albert     Albert     Albert
---------------------------------------------------
```
